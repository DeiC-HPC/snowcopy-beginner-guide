# Introduction
Welcome to this beginners guide for snowcopy. It's intended for people that are not yet comfortable using command line tools. It will give an introduction to basic commandline usage, object storage (S3) and snowcopy.

The contexts is as follows:
* What is object storage? 
* Basic commandline usage
* Using snowcopy to transfer files to and from object storage

Note, that if you were linked this guide directly, then the home for snowcopy is [https://github.com/DeiC-HPC/Snowcopy](https://github.com/DeiC-HPC/Snowcopy)

Please select your operating system in the drop-down top right for tailored examples.

Let's get started!
