# S3 compatibility

S3 was originally created by amazon for its AWS. Their service became so popular that other people copied the interface for it. Here "interface" is how programs interacts with S3. These "copies" or "clones" support various subsets of the AWS api. Therefore many tools only targets AWS because its stable and well-defined. 

Snowcopy aims to be widely compatible, but it's an ongoing effort. Information about the current state can be found here [https://github.com/DeiC-HPC/Snowcopy#compatability](https://github.com/DeiC-HPC/Snowcopy#compatability)

If you experience any problems with compatibility with a S3 server, please create a github issue or email us at snowcopy@deic.dk
